# 003 — Explicit migration to Amazon Bedrock

Date: 2026-09-13 · Status: accepted · Supersedes ADR 001 inference placement

## Context

Threadly is moving to Bedrock for five-intent assistance and visual Flows.
The existing summary pipeline and local inference need a controlled transition.

## Decision

Select inference through `INFERENCE_PROVIDER=legacy|bedrock`. Keep `legacy` as
the default until a configured AWS test-account smoke test passes. Bedrock mode
uses the workload's AWS credential chain and configured region/model IDs; it
does not fail over to Ollama or OpenRouter. Existing cloud input masking applies.

The first adapter uses text-only Converse, buffered into one SSE content chunk.
Only a nonempty assistant text response with `end_turn` is accepted. Blocking SDK
work runs in a worker thread, with bounded connect/read timeouts and one attempt.
Cancellation releases the caller; the in-flight SDK call finishes and closes its
client. It cannot be forcibly stopped by cancelling the coroutine.

Backend code remains responsible for user ownership, deterministic facts,
durable tasks, approvals and external writes. Visual Flows and the durable
dispatcher will be separate changes; adding this adapter does not deploy a Flow.

## Consequences

Set `BEDROCK_MODEL_ID` to an enabled Converse text model or inference profile
compatible with temperature and token limits; optionally configure a smaller
model. Restrict IAM invocation permission to approved resources. No account IDs,
model availability or successful live evaluation are assumed by the code.

Streaming latency and model-aware summary cache invalidation remain follow-up
work. Cached summaries may have been generated by the legacy provider. The
existing regex masker is retained, including its limits; it is not a privacy
guarantee or recipient resolver. Do not use masked generated addresses for sends.

API shape verified against the official
[Boto3 Converse reference](https://docs.aws.amazon.com/boto3/latest/reference/services/bedrock-runtime/client/converse.html).
