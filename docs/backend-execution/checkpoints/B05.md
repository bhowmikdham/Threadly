## Behavior and map

[Email action runbook](../../email-actions.md) maps worker, adapter, API result
fields, lifecycle diagram, error policy, configuration and B06 handoff.

The worker claims approved outbox jobs, refreshes credentials outside task/action
locks, then rechecks sources/account/consent/payload in a short transaction. It
commits one dispatch intent before POST, uses exact frozen MIME/thread ID, and
fences result publication by lease/version. Uncertain responses or expired intent
become unknown with held reconciliation work. Stale observations are retained
without overwriting terminal state. There is no write retry or model involvement.

## Focused second review

- Owner/task → action → account → job/attempt lock order; no reverse task lock in
  auth publication. Credential helper receives only the owned user ID and reloads
  in its own transactions. Source validation uses current stored context, not LLM text.
- Claim is not dispatch intent. Crashes before committed intent may reclaim a
  bounded preflight lease; crashes after intent must reconcile and cannot dispatch again.
- Attempt insert precedes executing update for database guards; terminal attempt
  evidence precedes terminal action in the same transaction. Commit failure rolls back
  both, leaving the original durable intent for expiry recovery.
- Post-cutoff cancellation records intent; it cannot recall mail. A disabled write
  gate before HTTP gives definite non-execution. Revocation after cutoff cannot
  promise prevention of an already authorized/in-flight write.
- Frozen MIME and saved thread ID only; fixed URL, no redirects/retries, bounded
  time/response bytes, no secret/provider text in errors/events. A valid Gmail result
  is API acceptance, not proof of recipient delivery.
- Late result never overwrites terminal evidence; pending late observation survives
  a later lease sweep. Missing-attempt corruption is held, not fabricated success.
- Existing source/account deletion guards preserve history. Retention/purge policy
  and full operator recovery remain B06/B19 release work.
