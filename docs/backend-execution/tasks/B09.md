## Implementation sequence

1. Define bounded native handlers for supported operations. Use parameterized owner-filtered queries, explicit time/folder/source scope, result caps and stable cursors.
2. Implement entity/commitment source records where required; distinguish extracted/inferred facts from user-confirmed state and retain provenance/corrections.
3. Generate an answer only over returned evidence refs; deterministic help/exact lookup can avoid a model. No result is explicit, not fabricated content.
4. Transform selected text as a bounded user-input artifact without granting mailbox/action authority. Clearly mark truncated/missing sources.
5. Wire installed handlers into capabilities/dispatcher and preserve unavailable compound behavior until B10. Add prompt/release versions and replayable model fixtures.
