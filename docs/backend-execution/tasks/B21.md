## Implementation sequence

1. Persist per-user consent, scope, quiet hours, cooldown/budget, dismiss/snooze feedback and version.
2. Implement authenticated Gmail push/watch renewal or approved polling with history cursor recovery, message/event dedupe and owned task linkage.
3. Run bounded suggestion eligibility/classification after sync; untrusted email cannot request broader tools or approve actions.
4. Persist suggestions as separate reviewable artifacts and user-triggered continuation; support stop/revoke and replay suppression.

## Acceptance assertions

Implement independent tests for these behaviors. Record each assertion in the checkpoint;
do not mark a live assertion passed using only a mock. Apply all relevant QUALITY-GATES checks.

- **B21-A1:** Duplicate/out-of-order events, expired watch/history cursor and process restart create at most one eligible suggestion per event policy.

- **B21-A3:** Prompt-injection email cannot send, book, change recipients or schedule its own follow-up.
