## Delivered behavior

`read_options` selects one bounded operation through the existing task API. Help
and search execute natively; rewriting uses the established masked model adapter
with only the selected body. Search never interprets Gmail query syntax or expands
source scope. Results have exact backend evidence IDs/quotes and accurate partial
coverage. A rewrite is a text suggestion, never a sent message or a saved email draft.

The read worker checks source ownership/version/existence before generation,
rechecks while fencing publication, and rejects stale results on artifact retrieval.
No database transaction spans inference. Typed options are frozen in `read_input`;
release metadata pins read schemas, prompt, limits, policy and model configuration.
Absent options preserve old request hashes and releases. Source deletion cascades
through existing owned capture/task relations; changed/deleted messages report stale.

See [runtime contract](../../assistant-bounded-reads.md) for examples and diagram.
