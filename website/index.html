How urgent it is

Three levels, drawn as a chevron. A thread that needs you today is visible from the other end of the list without reading a word of it.

Whether it is waiting on you

A reply arrow when the thread needs something back from you, and a small dash when it does not. Most of an inbox turns out to be the dash.

What it is about

Every thread is filed into one of six categories, so you know the subject of an email before you read its subject line.

Priority is a shape
before it is a colour.

Two chevrons up, one up, one down. The level survives a colour-blind eye, a dark theme and a greyscale print. Colour only confirms what the shape already said.

HighA deadline, money, or a person blocked on you
MediumReal work, but it keeps until tomorrow
LowNewsletters, receipts, notifications

The reply arrow marks a thread waiting on you. When nothing is owed, a five-pixel hairline takes its place, so every subject in the column still starts on the same vertical line.

Six things a thread turns out to be about.

Each one is a single glyph drawn on the same 16 pixel grid and the same 1.5 pixel stroke as Gmail's own icons, so a marked row still looks like a Gmail row.

What it deliberately does not do.

It keeps Gmail's row height

Forty pixels, unchanged. Both slots are fixed width, so nothing below shifts when a mark appears and your muscle memory for the list survives.

It follows Gmail's theme

No switch of its own. Threadly reads the theme you already chose. The priority colours move to their dark values for contrast; the chevron shapes do not change.

It adds no new place to look

Two slots in a row you already scan, and one panel in the space Gmail already reserves for add-ons. There is nowhere new to check.

This page follows your theme the same way. Switch it and watch the priority colours move while the shapes hold.
