# Decision records

Small, numbered, immutable. When we make a call that someone will later ask
"why on earth is it like this?", it gets an ADR. Supersede, don't edit.

Format: copy the template below into `NNN-short-slug.md`.

```markdown
# NNN — Title

Date: YYYY-MM-DD · Status: accepted | superseded by NNN

## Context
## Decision
## Consequences
```
