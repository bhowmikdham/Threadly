## Implementation sequence

1. Add opt-in indexing/deletion/versioning for sent mail with bounded retrieval and per-owner collections/access checks.
2. Supply style-only examples to draft generation separately from factual evidence; examples cannot supply commitments, names or recipients.
3. Gracefully fall back to unpersonalized draft generation when vector store is unavailable; record provenance and explicit limits.
4. Version prompt/evaluation data and run style-versus-factual-contamination eval before enabling.
