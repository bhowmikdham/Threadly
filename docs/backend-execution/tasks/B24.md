## Implementation sequence

1. Add owned uploads/file references with type/size allowlist, safe extraction, malware/content policy and bounded storage/retention.
2. Bind attachment IDs/hashes/MIME/filenames into artifact revisions and outgoing MIME/action payload; add/remove/replace always requires new approval.
3. Distinguish unreadable/unsupported/extraction-partial attachments from complete evidence; model text cannot invent file refs.
4. Update UI preview, MIME builder, reconciliation comparison and all relevant release/evaluation fixtures.
