## Implementation sequence

1. Implement InvokeFlow adapter with lazy SDK, bounded off-event-loop blocking work, stream size/time limits, validated outputs and saved execution/node provenance.
2. Map output/completion/error/input-required events to typed application results; missing completion, duplicate terminal data or stream truncation cannot publish success. Persist human waits in Threadly.
3. Implement service-authenticated read grants bound to owner/run/context/tool/expiry/nonce. No token pass-through or arbitrary URLs; apply existing cloud masking/privacy policy to new paths.
4. Export and version summary then reply/compose/other/plan/schedule graphs, prompt assets, Lambda read/validator configs and least-privilege role templates. Never add send/create_event nodes.
5. Replay identical native/flow contract fixtures; preserve old queued releases and provide rollback to prior pinned resources. Promote only after authorized AWS smoke tests.
