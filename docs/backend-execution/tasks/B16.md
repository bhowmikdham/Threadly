1. Define strict registry manifest mapping operation to native handler or published flow release identity and input/output schemas, tool grants, budgets and model/prompt/validator fingerprints.
2. Keep native current summary/reply/compose and all historical queued releases runnable; new tasks pin the selected manifest, retries retain it.
3. Validate enabled entries at startup/readiness and capabilities; unknown operation, missing release, mutable-only draft or malformed identifiers fail closed.
4. Add env/config samples and reproducible promotion/rollback interface with placeholders clearly labelled; no guessed AWS account/model/alias IDs.
