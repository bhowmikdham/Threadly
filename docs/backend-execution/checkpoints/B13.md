## Delivered behavior

Authenticated idempotent typed slot-query API, persisted original date anchors,
context-aware AM/PM clarification, Melbourne DST gap/fold handling, UTC working
windows and buffered multi-calendar conflicts. Up to three stable nonoverlapping
options, explicit unknown coverage and honest fewer/zero results. Source versions,
expiry and account/preference locks fence results and later reuse. Google reads
span no caller DB transaction. Participant zones are labels, not availability claims.

Request/anchor/evidence ownership is enforced in service code and composite database
FKs. Immutable input and terminal-publication guards protect stored query results.
Expired prior requests may supply an owned original anchor to a new corrected
request; this never revives old offers. Concurrent duplicate calls share one query.
A process interruption leaves a processing receipt to expire without automatic retry.

Full API examples, diagrams, constraints, error semantics and B14 handoff:
[Calendar slots](../../calendar-slots.md). Runtime API/data/architecture and progress/
workflow maps updated. Original T15 stays in_progress until its live criteria pass.
