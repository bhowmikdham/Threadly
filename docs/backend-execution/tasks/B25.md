## Implementation sequence

1. Define distinct reschedule/cancel/update action types with event/organizer/ACL checks and current etag/source version.
2. Make single occurrence versus full recurring series explicit; include attendees/resources/conference and notification policy in preview.
3. Use provider concurrency preconditions and action-specific reconciliation; compensation such as canceling an event requires a new approved action.
4. Preserve independent action results and create new approval whenever time/resource/recipient/notification scope changes.
