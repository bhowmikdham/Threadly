## Implemented behavior / acceptance mapping

Full user commands are partitioned into exact word spans with requested/prohibited/
context clauses. Schema and compiler reject unknown/gapped/overlapping outputs;
requested operation sets select installed kernels independent of label order.
Summary dependency must be explicit; lookup queries derive from original command
words. Missing bindings, ambiguous references, contradictions or unsupported whole
combinations create no task. Single-intent calls retain their existing separate API.

Proposals are saved for review. Explicit exact-hash confirmation atomically accepts
one compound task and consumes the plan, rechecking source/release and recompiling.
No model interpretation or review acts as send/booking approval. Historical task
schemas and releases remain unchanged. B10-A5/A7 gain reviewed-command compilation
and negative-clause fixtures. B10-A6 remains blocked by missing Calendar handlers;
A8 real Calendar failure recovery remains pending.

Structural word coverage is not a semantic guarantee. This reviewed release does
not claim a complete automatic planner, an in-place B08 plan editor, BERT integration
or live model-quality acceptance. Corrected inputs create a new immutable proposal.
