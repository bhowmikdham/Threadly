## Implementation sequence

1. Add create_event payload/preview and capability checks using common action lifecycle. Freeze destination calendar, stable event ID, fields/attendees/timezone, notification policy and slot source versions.
2. Recheck freebusy/ACL/account/preferences immediately before dispatch outside locks, then fence versions under ordered locks. Conflict produces new options/approval, never substituted time.
3. Call events.insert only from approved action worker. Persist action marker/event ID and result; timeout becomes unknown and reconciles with events.get plus field/marker comparison.
4. Handle ID collision/different event, lost scope, partial combined send+event outcomes and cancellation-after-dispatch without compensating deletes.
5. Keep writes default off until live Calendar gate; support only single event creation initially, no recurrence/reschedule/cancel.
